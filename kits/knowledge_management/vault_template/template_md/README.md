# Templates

One template per note type. Copy the relevant file into the appropriate folder and fill in the blanks.

| Template | Use for | Destination |
|---|---|---|
| `daily_plain.md` | Light days — time-tracked, no coding | `daily_obs/YYYY-MM-DD.md` |
| `daily_engineering.md` | Coding / bug-fix days (default) | `daily_obs/YYYY-MM-DD.md` |
| `decision.md` | ADR-style decision records | `decisions_obs/DNNN — Title.md` |
| `meeting.md` | Meeting notes + action items | `meetings_obs/YYYY-MM-DD — Title.md` |
| `person.md` | Stakeholders, teammates, clients, vendors | `people_obs/Name.md` |
| `research.md` | Tool / tech / vendor evaluations | `research_obs/Tool — evaluation.md` |
| `project.md` | Project or initiative overview | `projects_obs/Project name.md` |
| `planning.md` | Roadmaps, timelines, sprint plans | `planning_obs/Title.md` |
| `bug_fix.md` | Individual bug / issue fix records | `projects/<project>/` or `decisions_obs/` |

Reference: [[Daily Log & Timesheet]] · Session modes: `claude_config/sessions/`
