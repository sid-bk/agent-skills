# Decisions

Key work decisions — technical and business — with rationale and alternatives. Updated when a decision is finalised. The full record lives in `decisions_obs/`; this file is the searchable summary.

*Last updated: —*

---

## Format

```markdown
### [Decision title]
**Date:** YYYY-MM-DD
**Status:** Accepted | Superseded by [...]
**Decision:** What was chosen.
**Context:** What forced the decision.
**Alternatives considered:** What was rejected and why.
**Consequences / open questions:** Tradeoffs accepted, what remains unresolved.
```

Records in `decisions_obs/` are numbered sequentially: `D001 — Title`, `D002 — Title`, …
