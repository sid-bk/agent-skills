# Projects

## Template

```markdown
### [Project name]
**Location:** projects_obs/[name].md
**Status:** Active | In progress | Blocked | On hold | Done
**Goal:** One line — what "done" looks like.
**Current focus:** What's in flight right now.
**Owner / stakeholders:** [[person]]
**Open items:** the live threads — blockers, decisions pending, action items
**Last touched:** YYYY-MM-DD
```

**Status meanings:** *Active* (being worked now), *In progress* (live but not today's focus), *Blocked* (waiting on someone/something — note what), *On hold* (paused deliberately), *Done* (archive it).
