# Session: Planning

> Load alongside CLAUDE.md + projects/[project].md for sprint planning, task
> breakdown, and roadmapping.

---

## How to plan here

- Default to **Low** model unless the roadmap needs architectural reasoning.
- Break work into dependency-ordered units; each unit independently shippable where possible.
- Assign IDs (`T1`, `T2`, …) so other sessions and agent mode can reference them.
- Separate "must ship" from "nice to have"; name the critical path.
- Flag blockers (credentials, external confirmation, upstream tasks) explicitly.

## Output

- Task list with IDs, dependencies, and blockers → the project's task doc.
- Update `docs/current_task.md` (Next Up) and `projects/[project].md` (Current Focus).
